We're building an experimental personal portfolio powered by Chrome's built-in Prompt API (`window.ai`). The site lets a local SLM dynamically dictate full page layouts, themes, and content on the fly using `/public/portfolio.md` as its context base.

---

## Tech Stack & Architecture

- **Build Tool:** Vite + Vanilla TypeScript.
- **AI Engine:** Chrome Built-in Prompt API (`window.languageModel` / `self.LanguageModel`).
- **HTML Sanitization:** `DOMPurify`.

---

## Key Core Requirements

### 1. Data & Feature Detection

- Feature-check for Chrome's Prompt API on boot. Render an `ErrorFallback` UI with model download progress if missing/downloading, including a fallback link to raw `/public/portfolio.md`.
- Fetch `/public/portfolio.md` once at application startup and cache it as context in a persistent SLM session.

### 2. Theme Engine

- Prompt the local AI on page load to generate a JSON map of CSS variables (e.g., `--bg`, `--text`, `--accent`, `--layout-gap`) derived from `portfolio.md`.
- Inject these CSS variables directly into `<style id="theme">` on `document.head`.

### 3. Header & Navigation

- **Header Components:**
  1. Static Name / Brand title.
  2. Text Input Box to ask freeform questions about the portfolio (triggers an AI query to update the main canvas).
  3. Dynamic Navigation Bar featuring 4 tab buttons generated by the SLM on startup based on `portfolio.md`.

### 4. Main Canvas Layout & Content

- Give the SLM complete structural control over the canvas layout (single column, dual column, CSS grid, sidebars, etc.).
- Output MUST be pure semantic HTML tags + inline structure/layout styles—no executable JavaScript.
- **Streaming Pipeline:** Stream raw tokens -> Strip common SLM hallucination like Markdown code fences (` ```html `) -> Pass through `DOMPurify.sanitize()` -> Render

### 5. Static Footer

- Fixed footer displaying something alone: _"Content and layout dynamically generated via Your Browser's Local AI. So be careful with navigating as it'll trigger a regenerate."_ With icons to github, to linkedin, and to `/public/portfolio.md` for users to view the raw content.
